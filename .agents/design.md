# Design Principles (UX/UI 대원칙)

> **이 문서는 프로젝트의 모든 디자인(UX/UI) 결정을 관통하는 불변의 대원칙(Grand Principles)입니다.**
> 특정 CSS 라이브러리나 렌더링 기법(예: 글래스모피즘, 3단 레이아웃 등)은 트렌드에 따라 변경될 수 있으나, 아래의 UX 철학은 절대 타협하지 않습니다.

---

## 1. UX 대원칙 (Grand UX Principles)

### 1.1 User-Centric (오직 사용자의 편의성에 맞춘다)
*   모든 디자인 결정과 기능 추가의 궁극적인 기준은 **"사용자가 편리한가?"**입니다.
*   개발자나 디자이너의 자기만족(화려한 그래픽, 과도한 이펙트)을 위해 시각적 요소를 남용하지 않습니다. 
*   모든 요소(애니메이션, 팝업, 컬러 등)는 사용자의 목표 달성(학습, 정보 탐색)을 돕기 위해서만 존재해야 합니다.

### 1.2 User Journey Driven (유저 저니를 기반으로 파악한다)
*   디자인을 시작하기 전, 반드시 사용자가 어떤 맥락에서 들어와서 어떤 과정을 거쳐 나가는지(User Journey)를 먼저 파악합니다.
*   사용자의 여정을 3단계로 나누고, 각 단계별 페인포인트(Pain points)를 해결합니다.
    1.  **발견 (Discovery)**: 메인 포털에서 원하는 정보를 빠르고 정확하게 찾아낼 수 있도록 돕는다. (직관적 스캐닝, 즉각적 피드백)
    2.  **학습/소비 (Consumption)**: 본문 집중도를 높이고 이해를 돕기 위해 인지적 부하를 최소화한다. (가독성 최적화, 이해를 돕는 시각 보조자료)
    3.  **탐색/유지 (Navigation & Retention)**: 학습이 끝났을 때 길을 잃지 않고 다음 단계로 매끄럽게 유도한다. (명확한 네비게이션)

### 1.3 Frictionless Experience (마찰 없는 인지 경험)
*   시스템을 조작하고 정보를 습득하는 과정에서 발생하는 **인지적 부하(Cognitive Load)를 제로에 가깝게** 만듭니다.
*   사용자가 "이 버튼은 뭐지?", "다음엔 어디로 가야 하지?"라고 고민하게 만들면 실패한 디자인입니다.
*   일관성(Consistency)과 관습(Convention)을 준수하여, 사용자가 별도의 학습 없이도 본능적으로 사용할 수 있어야 합니다.

### 1.4 Separation of Principle and Implementation (원칙과 구현의 분리)
*   위 1.1 ~ 1.3항의 대원칙은 불변합니다.
*   하지만 이를 달성하기 위한 구체적인 UI/디자인 설계(레이아웃 폭, 컬러 팔레트, 애니메이션 라이브러리 등)는 언제든지 유연하게 변경될 수 있는 '수단'에 불과합니다. 특정 렌더링 기법에 얽매이지 않고 더 나은 방식론이 있다면 과감히 교체합니다.

## 2. Sub-Designs (Flexible UX/UI Guidelines)

> 이 섹션은 대원칙을 달성하기 위한 현재 시점의 구체적인 구현 가이드라인입니다. 상황에 따라 유연하게 수정될 수 있습니다.

*   **컴포넌트 일관성**: 경고 박스(Callouts), 배지(Badges), 페이지네이션(Pagination) 등은 카테고리(Crypto, Finance 등)가 달라도 시각적 언어(Visual Language)를 통일하여 마찰을 줄인다.
*   **스캐너빌리티(Scannability)**: 메인 포털의 카드 UI는 난이도, 소요 시간, 핵심 태그를 뱃지 형태로 제공하여 사용자가 1초 만에 내용을 훑어볼 수 있게 한다.
*   **시각 보조 (Visual Aids)**: 글로 이해하기 어려운 복잡한 개념(예: 암호학 공격 모델, 정렬 알고리즘 등)은 Anime.js 등을 활용하여 사용자가 조작 가능한 인터랙티브 시퀀스로 제공한다.
