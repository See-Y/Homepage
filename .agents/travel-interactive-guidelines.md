# 여행 블로그 인터랙티브 연출 가이드라인 (AI 보조)

> **핵심 원칙**: 무조건 AI를 쓰기 위해 억지로 기능을 넣는 것을 지양합니다. 철저히 **"독자의 몰입감 극대화"**라는 목적을 달성하기 위해 AI를 **'보조 도구 및 자동화 스크립터'**로만 활용합니다. 현재 웹 기술 수준에서 현실적으로 구현 및 최적화가 가능한 아이디어 모음입니다.

---

## 1. 시각적 몰입 극대화 (Visual Immersion)

### 1.1. 정적 사진의 3D 공간화 (Depth-Estimation Parallax)
* **목적**: 평범한 2D 풍경 사진에 생동감을 부여합니다.
* **AI의 역할**: 사전 빌드 단계에서 사진의 깊이 정보(Depth Map)를 AI로 추출합니다.
* **구현**: 스크롤을 내릴 때 전경(인물/사물)과 원경(풍경)이 미세하게 다른 속도로 움직이도록 하여(Ken Burns Effect), 사진 속으로 빨려 들어가는 듯한 입체적인 몰입감을 줍니다.

### 1.2. "찍지 못한 순간"의 위트 있는 삽화 대체
* **목적**: 사진을 남기지 못한 재밌는 에피소드의 시각적 공백을 채웁니다. (거짓 사진을 만드는 것이 아님)
* **AI의 역할**: 여행 중 아이스크림을 떨어뜨리거나, 길을 잃고 헤매던 텍스트를 AI 이미지 생성기에 넣어 **'귀여운 수채화나 스케치풍의 카툰'**으로 생성합니다.
* **구현**: 텍스트 옆에 배치하여, 실제 사진들 사이에서 환기 포인트와 유머를 제공합니다.

---

## 2. 동적 스크롤텔링 자동화 (Scrollytelling Automation)

### 2.1. 여행 궤적 및 지도 연출 스크립트 자동화
* **목적**: 스크롤텔링 구현 시 가장 번거로운 '좌표 하드코딩' 시간을 단축합니다.
* **AI의 역할**: 개발자가 여행기 텍스트만 주면, LLM이 문맥을 분석해 위/경도를 추출하고 `Leaflet.js`의 `flyTo` 이동 코드와 경로를 잇는 SVG 애니메이션 코드를 자동으로 작성해 줍니다.
* **구현**: 독자가 스크롤할 때마다 지도가 매끄럽게 다음 장소로 이동하며 궤적이 그려집니다.

### 2.2. 문맥 기반 테마(조명/날씨) 자동 연출
* **목적**: 글의 분위기와 화면의 분위기를 일치시켜 공감각적 몰입을 유도합니다.
* **AI의 역할**: 글의 감정이나 날씨("장대비가 쏟아졌다", "노을이 아름다웠다")를 AI가 파악해, 해당 챕터의 CSS 필터(색감 전환)나 Canvas 빗방울 파티클 코드를 적절히 매핑해 줍니다.
* **구현**: 지우펀 파트에서 비가 내리고, 단수이 파트에서 배경이 붉어지는 연출을 AI가 코드로 자동 어시스트합니다.

---

## 3. 접근성 및 편의성 (Accessibility)

### 3.1. 고품질 오디오북 (자연스러운 내레이션)
* **목적**: 화면을 뚫어져라 보기 힘든 상황이거나, 라디오처럼 여행기를 감상하고 싶은 독자를 배제하지 않습니다.
* **AI의 역할**: 최신 고품질 TTS AI를 활용해 여행기를 실제 사람처럼 억양과 감정을 담아 읽어주는 오디오 파일을 생성합니다.
* **구현**: 페이지 상단에 오디오 플레이어를 작게 띄우고, 오디오 재생 시간에 맞춰 스크롤이 자동으로 서서히 내려가는 모드를 지원합니다.
