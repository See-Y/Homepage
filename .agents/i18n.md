# 다국어 처리 (i18n)

> 한/영 전환에 관한 모든 규칙을 정의합니다.
> 새 페이지에 다국어 지원을 추가하거나, 번역 텍스트를 수정할 때 이 문서를 참고합니다.

---

## 기본 원칙

- 기본 언어: **한국어 (ko)**
- 지원 언어: **영어 (en)**
- 전환 범위: **전체 UI** (헤더, 푸터, 검색, 버튼, 페이지 콘텐츠 모두)
- 저장: URL 파라미터 `?lang=en` + `localStorage`

---

## 구현 방식

### 언어 감지 우선순위

1. URL 파라미터 `?lang=ko|en` (최우선)
2. `localStorage`의 `lang` 값
3. 기본값: `ko`

### HTML 속성

다국어 대상 텍스트에 `data-i18n` 속성을 부여한다:

```html
<!-- 단순 텍스트 -->
<h1 data-i18n="home.hero.title">안녕하세요</h1>

<!-- placeholder 등 속성값 -->
<input data-i18n="common.search.placeholder" 
       data-i18n-attr="placeholder" 
       placeholder="검색어를 입력하세요">

<!-- aria-label -->
<button data-i18n="common.theme.toggle" 
        data-i18n-attr="aria-label" 
        aria-label="다크모드 전환">🌙</button>
```

### 동작 흐름

1. 페이지 로드 → `i18n.js` 실행
2. 현재 언어 감지 (URL → localStorage → 기본값)
3. `document.querySelectorAll('[data-i18n]')` 순회
4. 텍스트 맵에서 해당 키의 번역 텍스트를 가져와 교체
5. `<html lang="ko|en">` 속성 업데이트
6. 언어 토글 버튼 클릭 시 → 언어 전환 → localStorage 저장 → URL 파라미터 업데이트 → 텍스트 재렌더링

## 새 번역 추가 절차

1. 이 문서의 해당 섹션 텍스트 맵 테이블에 새 키-값 추가
2. `i18n.js`의 텍스트 맵 객체에 ko/en 번역 추가
3. HTML에 `data-i18n="키"` 속성 추가
4. 테스트: 언어 전환 시 누락 없이 번역되는지 확인

---

## 주의사항

- 동적으로 생성되는 콘텐츠(카드 목록 등)는 생성 시점에 i18n 함수를 호출해야 한다
- 헤더/푸터는 `fetch` 후 삽입된 뒤에 i18n이 적용되어야 한다
- 언어 전환 시 페이지 리로드는 하지 않는다 (SPA 스타일 텍스트 교체)
- 콘텐츠 본문(노트 내용 등)은 i18n 대상이 아니다 — UI 텍스트만 전환
